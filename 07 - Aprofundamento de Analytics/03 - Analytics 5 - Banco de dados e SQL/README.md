### Analytics 5: Bancos de Dados + SQL do curso Profissão: Cientista de Dados.

O Módulo 24 oferece uma introdução abrangente ao mundo dos bancos de dados e SQL, abordando desde conceitos fundamentais até aplicações práticas em ambientes de ciência de dados. Vamos explorar a organização e o acesso eficiente aos dados, destacando a importância dos bancos de dados relacionais e não relacionais, além de práticas essenciais para cientistas de dados:

### Conceitos de Bancos de Dados
Entenda a diferença entre bancos de dados relacionais (SQL) e não relacionais (NoSQL), suas estruturas, características e aplicações específicas no mundo da ciência de dados.

### Introdução ao SQL
Aprenda os comandos básicos de SQL, como SELECT e FROM, para gerenciar e consultar dados em estruturas tabulares, e veja como integrar SQL com Python para análises mais robustas.

### Operações Matemáticas com SQL
Descubra como realizar cálculos diretamente no banco de dados utilizando funções como AVG e SUM, e a importância de renomear colunas para tornar os resultados mais claros e amigáveis.

### Habilidades:

1 - Apontar diferenças entre bancos de dados relacionais e não relacionais e suas aplicações.

2 - Descrever comandos SQL básicos, como SELECT e FROM, para buscar dados em tabelas.

3 - Aplicar funções SQL, como AVG e SUM, para realizar cálculos em colunas de dados.

4 - Analisar a integração de SQL com Python no Google Colab para processamento de dados.
