### Analytics 6: Operações Básicas SQL do curso Profissão: Cientista de Dados.
Neste módulo, vamos explorar as operações básicas de SQL, uma linguagem essencial para a manipulação e análise de dados em bancos de dados. Você aprenderá a utilizar comandos fundamentais para filtrar, ordenar e agrupar dados, habilidades cruciais para qualquer profissional que trabalha com dados:

### Filtragem de Dados com WHERE
Aprenda a utilizar o comando WHERE para filtrar dados com base em condições específicas. Explore operadores como LIKE, IN, e NOT IN para refinar suas consultas e obter resultados precisos.

### Manipulação de Strings e Sensibilidade a Maiúsculas
Descubra como as funções LOWER e UPPER podem ser usadas para realizar comparações de strings de forma insensível a maiúsculas, facilitando a filtragem de dados em suas consultas SQL.

### Ordenação e Agrupamento de Dados
Entenda como utilizar as cláusulas ORDER BY e GROUP BY para ordenar e agrupar dados de forma eficiente. Aprenda a aplicar funções agregadas como SUM, AVG, MAX e MIN para obter insights valiosos a partir dos seus dados.
