# Regressão - Conceitos Avançados do curso Profissão: Cientista de Dados.

Neste módulo, vamos explorar técnicas avançadas de regressão, focando na teoria e na aplicação prática dessas metodologias. Vamos abordar a regressão polinomial e técnicas de regularização, essenciais para otimizar modelos de regressão e prevenir o overfitting:

### Regressão Polinomial
Aprenda a capturar relações complexas nos dados que não seguem um padrão linear, utilizando a regressão polinomial. Esta técnica é uma extensão da regressão linear, onde as variáveis de entrada são transformadas em potências para ajustar curvas aos dados, em vez de linhas retas.

### Técnicas de Regularização
Explore as técnicas de regularização, como Regressão Lasso, Ridge e Elastic Net, que são fundamentais para otimizar modelos de regressão. Essas técnicas ajudam a prevenir o overfitting e a simplificar o modelo, melhorando seu desempenho em dados complexos.

### Aplicação Prática e Avaliação de Modelos
Aplique as técnicas aprendidas em cenários práticos, utilizando Python e a biblioteca SciKit-Learn. Avalie a eficácia dos modelos utilizando métricas como o R² e explore diferentes valores de alfa para otimizar o modelo de regularização.

Este módulo desafiará suas habilidades analíticas e de modelagem, preparando você para aplicar essas técnicas em cenários reais de análise de dados.
