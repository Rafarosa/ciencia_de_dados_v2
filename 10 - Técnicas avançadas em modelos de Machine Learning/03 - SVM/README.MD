# SVM do curso Profissão: Cientista de Dados

Neste módulo, vamos explorar o algoritmo de Support Vector Machine (SVM), uma ferramenta poderosa e versátil em ciência de dados, especialmente para problemas de classificação. Vamos nos aprofundar em suas características, aplicações e implementação prática:

### Fundamentos do SVM
Entenda como o SVM utiliza hiperplanos para maximizar a margem entre classes, reduzindo a probabilidade de erros de classificação. Explore a matemática por trás do algoritmo e a importância do parâmetro C na regularização.

### Implementação com Scikit-learn
Aprenda a implementar o SVM utilizando a biblioteca Scikit-learn em Python. Familiarize-se com o SVC (Support Vector Classifier) e aplique-o em problemas de classificação, como na base de dados "Fetal Health".

### Uso de Kernels
Descubra como os kernels permitem ao SVM lidar com dados não linearmente separáveis. Explore diferentes tipos de kernels, como linear, polinomial e RBF, e aprenda a escolher o kernel adequado para otimizar o desempenho do modelo.

Implementar e otimizar modelos de Support Vector Machine (SVM) para resolver problemas de classificação complexos utilizando diferentes kernels e parâmetros.
